## 문제 → 해결 (핵심 스토리) — 폼 정렬 CSS 클래스 체계

- **문제:** 고객사가 폼 필드가 항상 딱 맞게 정렬된 레이아웃을 요구. 하지만 작업허가서·신청서 등 화면마다 필드 수가 달라, 그대로 두면 컬럼이 어긋나거나 레이아웃이 비어 보이는 문제가 있었음
- **제약:** 이 프로젝트는 개발자 8명이 화면을 나눠 작업 — 각자 스타일대로 만들면 폼마다 정렬 기준이 달라져 전체적으로 일관성이 깨짐
- **해결:** 필드 개수에 따라 컬럼 수가 자동으로 맞춰지는 유연한 CSS 클래스 체계를 직접 설계. 8명의 개발자가 화면마다 이 클래스를 그대로 적용하기만 하면, 필드 수와 무관하게 항상 정렬된 폼 레이아웃이 나오도록 표준화
- **적용 화면:** 작업허가서 상세, 일반 작업허가 신청
- **결과:** 필드 수와 무관하게 전 화면 폼 레이아웃 일관성 확보 + 8인 개발팀 전체의 작업 표준화
- **배운 점:** 여러 개발자가 함께 만드는 프로젝트에서는 개인 스타일보다 재사용 가능한 CSS 시스템 설계가 우선이라는 것을 체감

## 포트폴리오 서술 구조

- **문제:** 고객사가 요구한 "필드가 딱 맞게 정렬된 폼 레이아웃"을 화면마다 다른 필드 수 + 8인 개발팀 환경에서 일관되게 만들어야 했음
- **해결:** 필드 개수에 따라 컬럼 수가 자동으로 맞춰지는 유연한 CSS 클래스 체계를 직접 설계
- **구현:** 재사용 가능한 CSS 클래스로 8명의 개발자가 공통 적용, 작업허가서·신청서 등 폼 화면 전반에 표준화
- **결과:** 필드 수와 무관하게 전 화면 폼 레이아웃 일관성 확보, 팀 전체 작업 표준화
- **배운 점:** 여러 개발자가 함께 만드는 프로젝트에서는 개인 스타일보다 재사용 가능한 CSS 시스템 설계가 우선이라는 것을 체감
