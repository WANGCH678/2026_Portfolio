|------|------|
| 발주처 | GS칼텍스 |

| 시스템명 | Dynamic Pricing System |

## 시스템 개요

GS칼텍스 주유소 네트워크의 **유류 가격 동적 관리 시스템**. 전국·지역별 Mogas(휘발유)·Diesel(경유) 가격 현황 모니터링, 프라이싱 시뮬레이션, LCC 입차 타당성 분석 기능 포함.

---

## 주요 화면 구성

### 대시보드 (메인)

![유가 관리 대시보드](../raw/Image/GS칼텍스 유가 관리 시스템_메인.jpg)

- **상단 탭:** 다이나믹 프라이싱 / LCC 입차 타당성 분석(NEW)
- **좌측 사이드바:** 프라이싱 현황 (대시보드, 타시대비, 부분별, 지사별) / 프라이싱 조회 / 주유소 시뮬레이션 / 조건 설정 / 관리자 설정
- **Mogas / Diesel 병렬 패널**
  - 오늘 가격: 1,667원 / 지역평균 +8 / 전국 1,662

  - 일별/월별 전환 탭
  - 정두가·EPP·판매량 3중 시계열 차트 (라인 차트)
  - 툴팁: 특정 날짜 호버 시 정두가/EPP/판매량 수치 팝업

## 기술적 구현 특징

| 구현 요소 | 설명 |
|---------|------|

## 포트폴리오 서술 구조

- **문제:** 수백 개 주유소의 가격을 수동으로 관리해 시장 변동에 빠르게 대응하지 못함
- **해결:** 전국·지역별 가격 현황을 실시간 시각화하고 동적 프라이싱 시뮬레이션 UI 제공
- **구현:** Vue 기반 대시보드, 라인 차트 라이브러리 연동, 병렬 패널 반응형 레이아웃
- **결과:** 담당자가 단일 화면에서 Mogas/Diesel 가격 추이와 경쟁사 비교 즉시 가능
- **배운 점:** 같은 구조의 데이터를 병렬 배치할 때 컴포넌트 재사용성 설계의 중요성
