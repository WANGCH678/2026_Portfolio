## 시스템 개요

민간 통일운동 지원 재단의 **공식 홈페이지**. 2015년 설립 후 국민모금운동 기반으로 통일 사업을 수행하는 재단의 사업 소개·현황·스토리를 일반 시민에게 전달하는 퍼블릭 웹사이트.

---

## 주요 화면 구성

### 홈페이지 메인

![홈페이지 메인](../raw/Project Image/통일과나눔 재단 홈페이지_main.jpg)

**상단 GNB:**
- 로고(통일과나눔) + 메뉴(재단소개·기획사업·지원사업·재단소식·후원안내) + 통일과미래·아카이브 보조 메뉴 + 로그인·검색

**섹션 구성 (위→아래):**

1. **Hero 슬라이더**
   - "우리는 오늘도 통일을 위해 한 그루의 나무를 심어가겠습니다."
   - 재단 미션 텍스트 + 배경 이미지

2. **사업소개 카드 섹션**
   - 5개 카드: 통일이해 준비사업 / 남북통합 정책연구 / UniKorea Grant / 통일인재 장학사업 / 통일 컨퍼런스
   - 번호 + 아이콘 이미지 + 제목 + 설명 + 더보기 버튼

3. **사업현황 통계 섹션**
   - 후원자 수: 153,800명+
   - 지원 프로그램 수: 16,800명+
   - 수혜자 수: 17,000명+
   - 사업금액: 18,000억원+

4. **전세계 파트너 섹션**
   - 세계지도 위 North America·Europe·Korea·Africa·Asia 거점 표시

5. **통일과 나눔 스토리 슬라이더**
   - 뉴스/행사 이미지 카드 + 제목 + 카테고리 태그

6. **공지사항 섹션**
   - 전체/공모/모집/행사 탭 + 3열 카드 (통일이해 준비사업·남북통합 책연구·UniKorea Grant)

7. **Footer**
   - SNS 링크(페이스북·유튜브·인스타그램·블로그) + 재단 연락처 + 저작권

## 포트폴리오 서술 구조

- **문제:** 재단의 사업 규모와 스토리를 텍스트로만 설명하면 방문자가 체감하기 어려움
- **해결:** 후원자 15만 명 등 핵심 수치를 스크롤 시 카운트업 애니메이션으로 강조, 세계지도로 사업 거점을 시각화, Hero 슬라이더로 미션 메시지를 첫 화면에 배치
- **구현:** 전체 섹션 퍼블리싱·프론트 개발 담당. 슬라이더, 세계지도, 카운터 애니메이션 구현
- **결과:** 숫자와 이미지 중심으로 재단의 규모를 첫 화면에서 직관적으로 전달
- **배운 점:** 퍼블릭 웹은 데이터를 정확히 나열하는 것보다 숫자를 시각적으로 강조하는 연출이 설득력을 만든다는 것을 체감
