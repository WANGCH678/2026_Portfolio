> **[핵심 Takeaway]**
> 자격요건이 "React 실무 경력"이 아니라 **"UI 구현 감각 + 디자인을 읽는 눈 + 새 도구 학습력"**이라는 점이 핵심 — OutSystems(Low-Code)에서 Figma 시안을 직접 화면으로 옮기고 JS로 로직을 바인딩해온 경험이 그대로 어필 포인트가 된다.
> Lucy Studio 자체가 "Figma → JSON 기반 UI → JS 로직 바인딩" 구조라서, OutSystems의 "비주얼 캔버스 + JS 커스텀 코드" 워크플로우와 개념적으로 유사하다. 포트폴리오에서 이 유사성을 명시적으로 언급하면 강점이 된다.

## 회사 개요

2015년 설립된 Flutter 플랫폼 개발 전문 기업. 금융권 MTS·HTS·WTS 구축 도메인 경험을 바탕으로 자체 크로스플랫폼 UI 개발 도구 **Lucy(Studio·SDK·TeamCloud·Deploy)**를 개발·운영한다. "앱을 만드는 회사가 아니라 앱을 만들 수 있는 플랫폼을 만드는 회사."

## 포지션 특징

- Flutter 코딩 직무가 아니라, 자사 도구 **Lucy Studio**로 금융 앱 화면을 개발하는 포지션
- Lucy Studio: Figma 디자인을 가져와 JSON 기반 UI로 구성하고, JavaScript로 비즈니스 로직을 바인딩하는 로우코드성 도구
- Flutter 숙련도보다 "UI 구현 감각·디자인을 읽는 눈·새 도구 학습력"을 더 중시함 (Lucy Studio는 입사 후 온보딩으로 학습)
- 시니어 밀도 높은 환경 (고급 이상 전문 기술 인력 54.5%)

## 주요업무

- Lucy Studio를 사용한 금융 앱 화면 개발 (MTS·HTS 화면)
- Figma 디자인 파일 → Lucy Studio 화면 변환 및 구현
- JavaScript 기반 비즈니스 로직 바인딩 (API 연결, 이벤트 처리)
- 재사용 가능한 화면 컴포넌트 설계 및 구조화
- 디자이너·Flutter 개발자와의 협업을 통한 화면 품질 검수

## 자격요건

- HTML·CSS·JavaScript 기본 이해
- UI 구현에 대한 관심 및 감각
- 디자인 파일(Figma 등)을 읽고 화면으로 구현한 경험 (학교·인턴·개인 프로젝트 포함)
- 팀과 소통하며 일하는 것에 익숙한 분
