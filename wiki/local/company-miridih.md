## 회사 개요

디자인 올인원 플랫폼 '미리캔버스'(가입자 2,000만 명)와 온라인 PoD 커머스 '비즈하우스'를 운영. 25년 매출 942억 원, 4년만에 약 5배 성장. 원티드 픽 기업(기업가치 2,800억).

## 팀 소개

- 웹&에디터 팀: 미리캔버스 코어 라이브러리로 프론트엔드 서비스 개발
- CSS transition, framer motion을 활용한 애니메이션
- 1700만 고객이 사용하는 미리캔버스 UI 제작

## 주요업무

- 미리캔버스 신규 기능 개발
- lazy loading, fine grained reactivity 등으로 성능 향상
- 애니메이션 적용을 통한 유저 경험 개선
- 테스트 코드 작성
