Core Concept키워드:- 파란 하늘- 시원한 사이다- 여름- 청량함- 차분함- 투명함- 부드러운 구름- 깨끗한 인상전체 디자인은 강한 블루가 아니라,  **흐린 하늘색 + 회색기 있는 블루 + 따뜻한 아이보리**를 섞은 톤으로 만든다.목표 인상:- 시원하지만 차갑지 않음- 산뜻하지만 과하게 튀지 않음- 차분하고 여백이 많음- 카드/배너/섹션 UI에 적용했을 때 부드럽고 안정적인 느낌---## 3. ### Color Usage

|Token|Hex|용도|
|---|---|---|
|`--sky-blue-100`|`#a0d8ef`|포인트 배경, 라벨, 아이콘, 얇은 라인|
|`--mist-blue-100`|`#e0eaec`|메인 배경, 카드 배경, 흐린 하늘 느낌|
|`--warm-ivory-100`|`#f0ebe5`|여백 배경, 텍스트 박스, 대비 완화|
|`--cider-blue-500`|`#65acc1`|주요 버튼, 강조 텍스트, active 상태|
|`--gray-blue-500`|`#9cb2af`|보조 텍스트, 비활성 UI, 그림자 대신 쓰는 차분한 색|

사용 규칙:

- 흰색 대신 `#f0ebe5` 또는 `#e0eaec`를 섞어 부드럽게 표현한다.
- 진한 네이비나 순수 블랙은 최소화한다.
- 강조색은 `#65acc1`을 사용하되, 넓은 면적에는 너무 많이 쓰지 않는다.
- 배경은 연한 하늘색/아이보리/회청색을 그라데이션으로 섞는다.

## 4. Gradient Direction

이미지의 그라데이션은 하늘과 구름처럼 부드럽게 번지는 느낌이다.

권장 방향:

```
background: linear-gradient(  135deg,  #f0ebe5 0%,  #e0eaec 35%,  #a0d8ef 100%);
```

또는 조금 더 차분한 카드 배경:

```
background: linear-gradient(  135deg,  #e0eaec 0%,  #9cb2af 100%);
```

주의:

- 경계가 강한 그라데이션 금지
- 채도 높은 블루 단독 사용 금지
- 배경에는 blur, opacity, soft overlay를 활용한다

## 5. Typography Mood

참고 이미지의 문자 디자인은 얇고 가벼우며 여백이 많다.

권장 스타일:

```
font-weight: 300;letter-spacing: -0.02em;line-height: 1.6;
```

제목:

- 얇은 산세리프
- 크지만 무겁지 않게
- 자간은 살짝 좁게
- 색상은 순수 검정 대신 `#4f6265` 계열 사용

본문:

- 가독성을 유지하되 부드러운 회색 블루 계열 사용
- 너무 많은 텍스트를 한 번에 넣지 않는다

예시:

```
.title {  color: #4f6265;  font-size: 32px;  font-weight: 300;  letter-spacing: -0.03em;}.description {  color: #6f7f82;  font-size: 15px;  line-height: 1.7;}
```

## 6. Layout Principles

이미지에서 느껴지는 핵심 레이아웃 원칙:

1. 여백을 넓게 둔다.
2. 요소를 빽빽하게 채우지 않는다.
3. 배경은 사진처럼 흐릿하고 부드럽게 처리한다.
4. 포인트 컬러는 작은 면적에만 사용한다.
5. 직선보다는 부드러운 라운드, 흐린 경계, 투명감을 활용한다.

권장 UI 요소:

- rounded card
- soft gradient section
- thin divider
- pale blue label
- translucent button
- glass-like panel
- floating circle decoration
- cloud-like blurred shape

## 8. Do / Don't

### Do

- 연한 블루와 회색 블루를 중심으로 사용한다.
- 여름, 사이다, 하늘, 구름 같은 이미지를 추상적으로 반영한다.
- 버튼과 포인트 요소만 선명한 블루를 사용한다.
- 배경은 부드러운 그라데이션과 투명감을 사용한다.
- 전체적으로 차분하고 깨끗한 UI를 만든다.

### Don't

- 강한 원색 파랑을 넓게 사용하지 않는다.
- 검정색 대비를 너무 강하게 만들지 않는다.
- 요소를 과하게 많이 넣지 않는다.
- 책 이미지를 그대로 복제하지 않는다.
- 장식용 패턴을 복잡하게 만들지 않는다.
