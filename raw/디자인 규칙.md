# 색채학 기초 정리

## 개요

색을 체계적으로 다루기 위해서는 색을 구성하는 기본 속성을 이해해야 한다.

색은 크게 다음 3가지 속성으로 정의된다.

1. 색상 (Hue)
2. 명도 (Value / Lightness)
3. 채도 (Saturation)

---

# 1. 색상 (Hue)

## 정의

색상은 빨강, 주황, 노랑, 초록, 파랑, 보라처럼 색 자체를 구분하는 속성이다.

## 색상환(Color Wheel)

색상은 일반적으로 원형 구조인 색상환으로 표현한다.

색상 변화 순서:

```
빨강→ 주황→ 노랑→ 초록→ 파랑→ 보라→ 빨강
```

## 실무 활용

색상을 변경한다는 것은 같은 명도와 채도를 유지한 상태에서 색의 종류만 변경하는 것을 의미한다.

예시:

```
빨강 → 파랑노랑 → 초록보라 → 주황
```

---

# 2. 명도 (Value / Lightness)

## 정의

명도는 색의 밝고 어두운 정도를 의미한다.

## 명도 구분

|구분|설명|
|---|---|
|저명도|검정에 가까움|
|중명도|중간 밝기|
|고명도|흰색에 가까움|

## 변화 방향

```
검정 ← 저명도 ← 중명도 ← 고명도 → 흰색
```

## 실무 활용

같은 색상이라도 명도에 따라 느낌이 크게 달라진다.

예시:

```
짙은 파랑 (저명도)중간 파랑 (중명도)하늘색 (고명도)
```

### UI 디자인 예시

```
Primary 900  ← 저명도Primary 500  ← 기준색Primary 100  ← 고명도
```

---

# 3. 채도 (Saturation)

## 정의

채도는 색의 선명함 또는 강렬함의 정도를 의미한다.

## 채도 구분

|구분|설명|
|---|---|
|저채도|회색이 많이 섞인 색|
|중채도|적당히 선명한 색|
|고채도|매우 선명한 색|

## 변화 방향

```
회색 ← 저채도 ← 중채도 ← 고채도
```

## 실무 활용

같은 빨강이라도 채도에 따라 전혀 다른 인상을 준다.

예시:

```
저채도 빨강 → 빈티지, 차분함중채도 빨강 → 일반적인 UI 색상고채도 빨강 → 경고, 강조
```

---

# 색의 3요소 관계

모든 색은 아래 3개 값의 조합으로 표현할 수 있다.

```
색 = 색상(Hue) + 명도(Value) + 채도(Saturation)
```

예시:

```
색상: 빨강명도: 높음채도: 높음→ 밝고 선명한 빨강
```

```
색상: 빨강명도: 낮음채도: 낮음→ 어둡고 탁한 빨강
```

---

# UI/UX 디자인 관점 핵심 규칙

### 색상(Hue)

- 브랜드 아이덴티티 결정
- 카테고리 구분
- 상태 구분

예시

```
파랑 = 정보초록 = 성공주황 = 주의빨강 = 오류
```

### 명도(Value)

- 계층 구조 표현
- 배경/텍스트 대비 조절
- 접근성 확보

예시

```
고명도 배경저명도 텍스트
```

### 채도(Saturation)

- 시선 집중도 조절
- 중요도 표현

예시

```
고채도 = CTA 버튼중채도 = 일반 인터랙션저채도 = 비활성 상태
```

# 톤(Tone)

## 정의

톤(Tone)은 색의 **명도(Value)** 와 **채도(Saturation)** 의 비율이 비슷한 색들을 그룹으로 묶은 개념이다.

즉,

```
색상(Hue)이 달라도명도와 채도가 비슷하면같은 톤(Tone)
```

으로 분류한다.

---

# 톤 차트 구조

```
위쪽 = 명도 높음 (밝음)아래쪽 = 명도 낮음 (어두움)왼쪽 = 채도 낮음오른쪽 = 채도 높음
```

---

# 디자인의 4대 원칙 (CRAP)

좋은 디자인은 단순히 예쁜 것이 아니라 정보를 빠르고 정확하게 전달하는 것이다.

디자인의 핵심 원칙은 다음 4가지로 정리된다.

```
DesignPrinciples:  - Proximity  - Alignment  - Repetition  - Contrast
```

실무에서는 흔히 **CRAP 원칙**이라고 부른다.

```
C = Contrast (대비)R = Repetition (반복)A = Alignment (정렬)P = Proximity (근접)
```

---

# 1. 근접성의 원리 (Proximity)

## 정의

관련 있는 정보끼리 가까이 배치하여 하나의 그룹으로 인식시키는 원칙

---

## 잘못된 예

```
사진A설명A사진B설명B
```

사진과 설명이 멀리 떨어져 있음

↓

사용자가 관계를 해석해야 함

---

## 올바른 예

```
사진A설명A사진B설명B
```

↓

즉시 그룹으로 인식

---

## 핵심 규칙

```
Proximity:  related:    distance: small  unrelated:    distance: large
```

```
[상품 이미지][상품명][가격]
```

가까이 배치

```
[상품 이미지][상품명][가격]

```

# 2. 정렬의 원리 (Alignment)

## 정의

보이지 않는 기준선을 따라 요소를 정렬하는 원칙

---

## 핵심 개념

사용자는 눈에 보이지 않는 선을 따라 정보를 읽는다.

---

## 잘못된 예

```
이름      주소전화번호
```

정렬 축이 없음

↓

산만함

---

## 올바른 예

```
이름주소전화번호
```

같은 시작선

↓

안정감

---

## 규칙

```
Alignment:  left:    default  center:    special_only  right:    numeric_data
```

---

## UI 적용

### 폼

```
이름이메일전화번호주소
```

모두 같은 축

---

### 리스트

```
상품명상품명상품명상품명
```

동일 정렬

---

## 효과

```
effect:  - 통일감  - 안정감  - 전문성
```

---

# 3. 반복의 원리 (Repetition)

## 정의

같은 디자인 요소를 반복 사용하여 일관성을 만드는 원칙

---

## 반복 가능한 요소

```
elements:  - 색상  - 타이포그래피  - 버튼  - 아이콘  - 간격  - 카드
```

---

## 브랜드 예시

```
Brand:  color: Red  logo:    repeat  typography:    repeat
```

명함

↓

웹사이트

↓

앱

↓

포장지

↓

광고

모두 동일한 규칙 사용

---

## UI 적용

### 버튼

```
Primary ButtonPrimary ButtonPrimary Button
```

모두 동일 디자인

---

### 아이콘

```
24px24px24px24px
```

통일

---

## 효과

```
effect:  - 브랜드 인지도 증가  - 학습 비용 감소  - 사용성 향상
```

---

# 4. 대비의 원리 (Contrast)

## 정의

중요한 정보를 눈에 띄게 만드는 원칙

---

## 핵심 개념

모든 것이 중요하면 아무것도 중요하지 않다.

---

## 잘못된 예

```
모든 텍스트크기 동일색상 동일굵기 동일
```

↓

우선순위 없음

---

## 올바른 예

```
제목  ↓부제목  ↓본문
```

정보 계층 존재

---

## 대비를 만드는 방법

### 크기

```
Title:  32pxSection:  24pxBody:  16px
```

---

### 색상

```
Primary:  #000000Secondary:  #666666Muted:  #999999
```

---

### 굵기

```
Heading:  BoldBody:  Regular
```

---

### 여백

```
SectionGap:  64ContentGap:  16
```

---

## UI 적용

### CTA 버튼

```
background:  primary_colortext:  white
```

대비 최대

---

### 카드

```
title:  bolddescription:  regularmeta:  muted
```

---

## 효과

```
effect:  - 시선 유도  - 중요도 전달  - 전환율 증가
```

---

# 실무용 디자인 체크리스트

```
Checklist:  Proximity:    - 관련 정보끼리 붙어있는가  Alignment:    - 보이지 않는 기준선이 있는가  Repetition:    - 동일 컴포넌트가 동일하게 보이는가  Contrast:    - 중요한 정보가 가장 먼저 보이는가
```
